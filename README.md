# 🌱 Field Shift — Adapting Farms with NASA Data

**Field Shift** is a bilingual, voice-enabled farming assistant designed to make climate information easier to understand and access for farmers.

## 🌍 About the Project

Field Shift focuses on Krishna district, Andhra Pradesh, and uses NASA POWER climate data to help users explore rainfall and temperature information through a simple dashboard.

The project aims to bridge the gap between complex climate data and farmers by providing information in English and Telugu.

## ✨ Key Features

- **Bilingual Support:** Switch between English and Telugu.
- **Voice-Based Assistant:** Ask questions using your voice and receive spoken answers.
- **NASA POWER Integration:** Displays rainfall and temperature information.
- **Climate Dashboard:** Shows annual climate summaries and monthly rainfall charts.
- **Crop Rotation Explorer:** Presents locally relevant crop rotation options, including:
  - Paddy → Blackgram (వరి → మినుములు)
  - Paddy → Greengram (వరి → పెసలు)

## 🛰️ NASA Data

The prototype uses NASA POWER daily point data for 2025, using a representative location near Machilipatnam, Krishna district.

- **Rainfall:** PRECTOTCORR
- **Temperature:** T2M
- **Data source:** [NASA POWER](https://power.larc.nasa.gov/)

The displayed values represent the selected point location, not an average for the entire district.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js
- NASA POWER API
- Browser Speech Recognition
- Browser Speech Synthesis

## 🚀 Project Goal

Our goal is to make climate information more accessible to farmers through regional-language support, voice interaction, and easy-to-understand visualizations.

## ⚠️ Limitations

This is a prototype. Crop rotation options are informational suggestions and are not generated directly by NASA data. Actual crop suitability depends on soil conditions, water availability, season, and local agricultural guidance.

## 🔮 Future Scope

- Expand coverage to more districts.
- Include additional climate indicators.
- Improve agricultural recommendations with local expert inputs.
- Develop a more comprehensive farmer-support assistant.
